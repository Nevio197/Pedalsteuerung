Einstellungen

Pedalzugriff, Erkennung und Verbindungen.

Pedalzugriff

Aktiviere Exklusiv, bevor du Steam oder ein Spiel öffnest. Programme, die das Pedal bereits geöffnet haben, können weiter Eingaben erhalten. Starte sie bei Bedarf neu.

Im Modus Geteilt können andere Programme das Pedal lesen. Spiele können gesendete Tastenkürzel separat empfangen.

Tastenerkennung

Stelle ein, ab wann Halten zählt und wie schnell zwei Drucke aufeinanderfolgen müssen.

Discord und Tastenkürzel

Erlaube unter macOS den Zugriff auf Bedienungshilfen. Stelle in Discord dasselbe Kürzel ein und verlasse die Kürzel-Seite vor dem Test.

Tastaturzugriff wird geprüft.

OBS und Stream Deck

Für OBS aktiviere den WebSocket-Server und verwende dessen Port und Kennwort.

Für Stream Deck lege Aktionen auf das MCP Deck. Der integrierte HTTP-Server verwendet standardmäßig Port 29001, der separate Elgato MCP Server Port 9090. OBS und Stream Deck senden keine Tastenkürzel an das aktive Fenster.
